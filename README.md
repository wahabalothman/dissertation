# Dissertation: how conspiratorial claims acquire political authority

Everything for the project lives here except raw data (see `data/manifest.qmd`).

| Folder | What goes in it |
|---|---|
| `notes/` | weekly log; decisions recorded under a Decisions heading |
| `theory/` | gap paper, transmission framework, mechanism and rivals |
| `design/` | codebook, sampling rule, falsification table, preregistration drafts |
| `data/` | manifest and coverage log; derived tables only |
| `analysis/` | one folder per chapter; scripts numbered in run order; outputs regenerated by scripts |
| `manuscript/` | dissertation chapters (Quarto book, later) |
| `site/` | CV and site styling |

## Rules
1. Every output has the script that made it next to it.
2. Raw data never enters the repo.
3. Decisions go in the weekly log under Decisions.
4. Commit at least once per working day.
